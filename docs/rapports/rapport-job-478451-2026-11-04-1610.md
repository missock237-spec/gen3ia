  (lib/ondes/manifold.ts) : le commentaire annonçait
  `atan2(Σ s·cos, Σ s·sin)` alors que le code — validé par les tests —

  comportement, mais le commentaire aurait induit un lecteur en erreur.
- **Correctif** : commentaire aligné sur le code réel et sur le test, la
  relation miroir documentée explicitement. **Zéro changement de
  comportement** ; suite complète relancée avant push.
