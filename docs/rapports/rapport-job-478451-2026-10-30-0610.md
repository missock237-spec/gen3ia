## 9. Enseignements

### 9.1 Une mention d'URL « blanchit » un endpoint hors du garde (piège verrouillé)

Le garde anti-code-mort détecte les références **par chaîne de caractères** dans la surface utilisateur. Écrire « (/business/pulse) » dans une phrase honnête de la page aurait fait disparaître pulse de la baseline **sans lui donner d'UI** — un faux vert. Correctif : mention sans chemin littéral + verrou dédié documentant la règle (« une mention n'est pas une UI »). Toute future page qui évoque un endpoint orphelin devra suivre la même discipline.

### 9.2 Le verrou lit la source octet par octet (rappel it.31, payé une 2e fois)

L'assertion « mission agent coûteuse » a échoué parce que le JSX coupait la phrase entre deux lignes. Même famille que la leçon JSDoc it.31 : un verrou qui cherche une phrase doit soit matcher une sous-chaîne garantie sur une ligne, soit le composant doit garantir la ligne. Corrigé côté source (phrase sur une ligne).

### 9.3 Clôture de lot = vérifier le registre ET le discours

Fermer un lot de code mort, c'est (a) câbler l'UI, (b) retirer les entrées de baseline, (c) **ajuster le discours de la page** (annonces de vagues précédentes devenues fausses) et (d) mettre à jour les verrous qui assertent ce discours. Le point (c) est ce qui a produit les 2 incidents dev de ce tick.
