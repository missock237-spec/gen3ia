## 3. Limites honnêtes (demandé : « 10 millions × 7 par domaine »)

1. **Échelle physique** : 10 M × 7 modalités × N domaines = pétaoctets —
   le sandbox offre 9,9 Go de disque, 3 Go de RAM, 2 cœurs CPU, 0 GPU.
   Livré : ~1,97 M lignes textuelles vérifiables + 3 340 médias réels.
   Le pipeline (générateurs seedés + scripts) **monte à l'échelle demandée
   sur une machine adaptée** (le générateur 18 domaines produit 100 k lignes/
   domaine en ~7 s/domaine ; les corpus couleurs/raisonnement sont
   paramétriques via `build_v5_datasets.py`).
2. **Entraînement neuronal profond** : gen3-core (Gemma 3 QLoRA) refuse par
   conception tout CPU — exécution Colab/A100 requise (notebooks v4 commis).
   La couche SNN apprise in-app reste honnêtement rapportée (~6 % : limitation
   architecturale du hachage 38 neurones, cf. docstring `detecterDomaine`).
3. **Production** : gen3ia.online injoignable depuis le sandbox
   (HTTP 000 — connect timeout 209.74.86.62:443). La panne VPS est déjà
   documentée et escaladée (cf. rapport it.149 : « VPS down depuis 08:36Z,
   escalade #163, intervention console requise »). La relance CD a été
   déclenchée par push (CI + Déploiement continu VPS + Guérisseur) ; le build
   est archivé en release `cd-latest` — déploiement en mode pull dès le
   rétablissement SSH (`docs/exploitation/ssh-bloque-runbook.md`).
