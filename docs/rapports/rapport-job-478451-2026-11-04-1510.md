## 3. Phase 1 — Tenseur d'Onde Commun (manifold)

**`lib/ondes/manifold.ts`** (nouveau, ~600 lignes) : toutes les modalités partagent UN format — champ d'oscillateurs complexes `[amplitude, phase]` quantifiés **2 × Uint16 = 4 octets/état** (contre 8 octets FP32 : **−50 % de mémoire**), accrochés à une fondamentale `F0` commune :

- quantification bornée, jamais de NaN en VRAM (erreurs max : 9,6·10⁻⁵ rad / 1,5·10⁻⁵ en amplitude) ;
- **encodeur multi-fréquence** : chaque jeton module `F0_j = F0_base · 2^octave` (hash FNV-1a, déterministe) et dépose une série harmonique `A_k = A_j/k` (timbre Fourier) — les collisions de créneaux se résolvent **par physique** (superposition complexe), pas par écrasement ;
- superposition complexe = interférence constructive/destructive (fusion de modalités sans concaténation) ; ordre de Kuramoto `r`, énergie `ΣA²` ;
- conversions modalité ↔ manifold : **audio** par démodulation cohérente (battement avec la porteuse → amplitude RMS + phase locale), **image/vidéo** par ondelettes de Haar (contraste → amplitude, orientation du gradient → phase).

## 4. Phase 2 — Micro-décodeurs WebGPU + miroirs CPU

**`lib/ondes/shaders-manifold.ts`** : trois compute shaders WGSL ; **`lib/ondes/micro-decodeurs.ts`** : leurs miroirs CPU exacts (même règle que `moteurs-webgpu.ts` — le GPU accélère, le CPU spécifie, le déterminisme est bit à bit) :

| Modalité | Shader | Physique |
|---|---|---|
| Image | `decoderImage` (workgroup 8×8) | chaque harmonique active = ondelette porteuse orientée (angle d'or), détail Haar, **normale par gradient analytique du champ**, éclairage lambertien |
| Audio | `decoderAudio` (workgroup 256) | oscillateurs sinusoïdaux **pilotés par phase** : F0 du tenseur transpose la hauteur (F0 audible 110 Hz × 3 octaves), amplitudes = enveloppe spectrale ; normalisation anti-saturation ; WAV 16 bits réutilisé (`versWav`) |
| Vidéo | `deriverTrame` (8×8) | **dérive de phase** : trame T+1 = trame T échantillonnée bilinéairement à travers la matrice de déphasage `(dx,dy) = A·(cosθ,sinθ)·8 px`, + résurrection d'énergie anti-affadissement |

Contrat partagé : **activation sparse** (`seuilSparse = 0.02`) saute explicitement les harmoniques inactives dans les trois shaders.

## 5. Phase 3 — Optimisation mémoire & exécution mobile

- `executerSparse` : exécute une opération SEULEMENT sur les nœuds actifs — le test prouve **sparse == dense restreint aux actifs** (invariant du calcul à nœuds actifs) ;
